# Telegram Bot - Упоминание всех участников группы

Бот для Telegram, который позволяет упомянуть всех участников группы одной командой.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Получите токен бота:
   - Напишите [@BotFather](https://t.me/botfather) в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям для создания бота
   - Скопируйте полученный токен

3. Откройте файл `bot.py` и замените `YOUR_BOT_TOKEN_HERE` на ваш токен:
```python
TOKEN = "ваш_токен_здесь"
```

## Запуск

```bash
python bot.py
```

## Использование

1. Добавьте бота в вашу группу
2. Сделайте бота администратором группы (необходимо для получения списка участников)
3. Используйте команду `/all` чтобы упомянуть всех участников
4. Можно добавить сообщение: `/all важное объявление`

## Команды

- `/start` - Приветственное сообщение
- `/all [сообщение]` - Упомянуть всех участников группы с необязательным сообщением
